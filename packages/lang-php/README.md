# @n-dx/lang-php

> **This is an internal package of [`@n-dx/core`](https://www.npmjs.com/package/@n-dx/core).** Install `@n-dx/core` instead.

The PHP language pack: the pinned tree-sitter-php grammar, which parses PHP mixed with HTML. It does not report facts yet. Install it with `ndx sv pack add php`.
