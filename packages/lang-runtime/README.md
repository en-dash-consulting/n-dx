# @n-dx/lang-runtime

> **This is an internal package of [`@n-dx/core`](https://www.npmjs.com/package/@n-dx/core).** Install `@n-dx/core` instead.

The tree-sitter parser runtime that language packs load: web-tree-sitter, the runner, the tree-sitter pack types, grammar checks, the captures-to-facts helpers and the pinned grammar build script.
