0.10.0 is the v2 migration release. `ndx migrate` moves a v1 PRD (`prd_tree/`) to the v2 product and change layers, `ndx init` starts new projects on v2, and rex commands on a v1 PRD print one deprecation line naming `ndx migrate`; the release after this one refuses v1 PRDs. Every `@n-dx/*` package is versioned together, so they all move to 0.10.0.
