Tighten the OS sandbox profiles. Confined processes can no longer rewrite the repository's git control files (`.git/config`, `config.worktree`, `commondir`, `hooks/`, `info/attributes`, a linked worktree's `.git` file and common directory) or move the git directory away, so hench's unconfined git cannot be steered into running a program a child configured. A `.n-dx.local.json` the repository commits no longer sets the sandbox mode or network. The macOS vendor profile drops raw UDP 53 for the system resolver's socket, limits Unix sockets to the project and scratch directories, and no longer admits all egress through a local-address rule; every macOS profile allows only named Mach services. Read-only toolchain roots at or above the home directory are dropped, and ndx home (the dashboard token, for the vendor CLI), `.git-credentials`, Cargo credentials, `.codex/auth.json` and `.pypirc` are denied. Under bubblewrap a credential or config file is masked with an empty file instead of a tmpfs, which bwrap refused, failing the spawn; a networked child gets the systemd-resolved directory read-only; and a caller can opt in to placeholders that stop a child creating an absent protected path such as `.ndx/`.
