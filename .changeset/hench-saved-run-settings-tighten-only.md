A task's saved `run` block can only tighten a run: `permissionMode`, `skipTestGate`, `maxTurns` and `tokenBudget` are honoured when they are stricter than the operator's flags and config and ignored with a `saved-setting-widens` warning otherwise, so `ndx work --resolve` reports the key that really won. An absent or empty `guard.allowedGitSubcommands` grants the language baseline to the Claude CLI, never a blanket `Bash(git:*)`, and the policy fingerprint hashes it the same way. While a repository is not trusted, `applyRepoTrust` also drops `guard.env.allow` and reverts a tracked `claudePath` and `apiKeyEnv` unless `.n-dx.local.json` sets them.
