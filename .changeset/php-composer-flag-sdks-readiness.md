A PHP repository that requires a feature-flag SDK in `composer.json` (`require` or `require-dev`) now scores on the readiness feature-flags dimension, with the `composer.json` line as evidence. Recognized packages include LaunchDarkly, Unleash, Flagsmith, ConfigCat, Split, GrowthBook, OpenFeature, PostHog, Statsig, DevCycle, Optimizely, Flipt, Laravel Pennant, Flagception, qandidate/toggle and opensoft/rollout. Readiness for repositories without a `composer.json` is unchanged.
