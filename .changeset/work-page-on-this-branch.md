On a branch with a work set, the Work page opens with "On this branch", grouped by change with Remove, and "Not on a branch" with Add. A task on the branch through its change says "via its change". Ready to run lists only the set, and an empty set names `{cli} work --any`. The work-set read also returns the open units not on the branch. The default branch, a detached HEAD and a branch with nothing assigned render as before.
