Zone judgments see what the code calls itself, and findings point at files. A zone's evidence now carries the symbol names its inbound import edges name, the exported top-level declarations of its sampled files, and its test file names, fed to the naming, fragility, heuristic and finding-evidence requests; a run with neither an import graph nor a project directory produces the state it always did. Zone names gain three candidates beside the directory ones — the subject its exported symbols share (`StandupService`, `StandupRepo`, `useStandup` → "Standup"), the title of the nearest README, and the package description — deduplicated against each other. Six finding kinds are now derived from the graph and anchored on the edges that produced them: layering violation, cycle member, hub file, test-only module, dead export, and a cross-zone crossing that bypasses the target's entry points; each is judged against those same edges, standing at or above 0.7 and dropping to `info` at or below 0.3. The per-zone cohesion, coupling, breadth and entry-point-width lines they replace now emit at `info`, since they restate a metric and name no file. Finally, a project's own architecture rules are extracted once from `CLAUDE.md`, `ARCHITECTURE.md`, `AGENTS.md` or `hints.md` — cached by document hash — and each cross-zone edge class is checked against them, with a confirmed violation becoming an `anti-pattern` that quotes the line it breaks. A repository that declares no such rules makes no call. All judging is inert without `TYPESAFE_API_KEY`; the findings and their anchors are produced either way.
