0.8.0 — Find your way

A single `.ndx/` directory for project state, with `ndx migrate-layout` to move
an existing project onto it. A reorganised dashboard: views are stages, settings
are three pages (Robot Wrangler, Workflow, Project) on a shared save frame, and
every moved path redirects. Per-vendor agent models with a live model catalog,
per-field resolution of the legacy `claude.*` keys, and a preflight banner and
run summary on the interactive commands.

Every other changeset in this release is a `patch`, which is the repo default
and correct for each change on its own. This one makes the aggregate a minor, as
the 0.8.0 epic requires.
