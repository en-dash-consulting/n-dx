Start Working runs in one click. The button starts the run with the task's saved run settings; a task with none first has the project defaults the Prepare task modal would show saved on it as its `run` block, so the settings the run used are visible and editable afterwards. The ▾ arrow now opens the Prepare task modal directly instead of a menu. The run-mode picker governs the click and is named on it ("Start working · until done"). If the defaults cannot be saved, or someone else saved settings on the task in between, nothing starts and the reason stays on the button.
