The face's sync with rex holds to rex's answer. A write rex refuses is put back to rex's value and said once in the rail instead of being retried every run. Choosing `deleted` is refused rather than deleting the item and its children. A completion rex holds for a hench run is not logged as written. The dev-server door admits only the page it served, through a per-launch key, and skips the re-emit when nothing the projection reads has changed. `ndx graview info` and the serve hand-off name the port the running hub bound, which `ndx start --port` may have changed.
