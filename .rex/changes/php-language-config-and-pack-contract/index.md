intent: "PR 1 of the PHP language-pack stack (base: main). Today `.php` sits in lang-kit's `FALLBACK_LANGUAGE_EXTENSIONS` (packages/lang-kit/src/detect.ts), so a PHP repository is analysed with the TypeScript config, and the pack contract (packages/lang-kit/src/pack-contract.ts) has no symbol kinds or import guard for PHP. This change adds a `php` LanguageConfig to lang-kit and the contract additions decided as D3. No pack exists yet: PHP files are inventoried and classified only.\n\nLane rules (PHP pack; decisions made 2026-11-12):\n- D1: open-core, opt-in `@n-dx/lang-php` (`ndx sv pack add php`).\n- D2: config reads and flag checks become new fact kinds `configReads` and `flagChecks`, written to a new language-neutral `config.json` (a named exception to the 2026-10-12 rule that facts go only into existing artifacts; Hal reviews).\n- D3: symbol kinds `trait`, `namespace`, `constant`; ImportGuard `conditional`; dynamic includes with a literal prefix carry candidate files that never become import edges.\n- D5: externals are named as written: `php:<first namespace segment>`, or the PSR-0 prefix for un-namespaced classes (`php:Zend` from `Zend_Db_Table`). The Composer package goes in the in-memory `module` field. PHP extensions are not externals.\n- Analyze output stays byte-identical for every repository without PHP files, and for PHP repositories without the pack except where a change says otherwise.\n- LS16: no PHP toolchain is used; composer.json, php.ini, .htaccess and similar files are read as text. LS3/LS4: no PHP versions or end-of-life dates from memory; version boundaries cite the php.net migration guides.\n- Agents cannot use the network, run `pnpm install`, read `~/.cache`, or write under `.claude/`. The operator does those steps; task descriptions name them.\n- Record measurements with append_log on the task.\n- Patch changesets with scoped package names.\n- Before finishing, run the six static root policy tests: tests/e2e/architecture-policy.test.js, domain-isolation.test.js, shell-spawn-inventory-policy.test.js, wall-clock-inventory-policy.test.js, layout-literal-policy.test.js, obfuscated-code-policy.test.js."
