intent: "From the 2026-11-12 feature-flag cleanup handoff (Project settings redesign, decisions PS1-PS6, each taken at its recommended option). Today Settings › Project is one long scroll of 22 controls: four real project settings (language, merge threshold, zone pins, port) and 18 feature-toggle cards grouped by package, with no way to jump to a section or search.\n\nDecisions:\n- PS1 Navigation: Project expands in the Settings overlay nav to list its sections, and the highlight follows scroll. Not tabs (they hide sections and break the scan-everything view) and not a sticky jump bar. One scroll keeps one SettingsFrame with one leave guard.\n- PS2 Grouping: by what you are changing, not by package or command. People look for \"stop committing for me\", not \"Git package flags\".\n- PS3 Search: this page only for now; search across all settings pages needs a shared index and is a separate change.\n- PS4 Config keys: shown small and monospace on every row; it ties the page to ndx config and .n-dx.json, and search can match it.\n- PS5 Fold in change 01856e28 (show fail-forward, auto-commit of generated files and the token budget column as ordinary settings): the new groups already present those three preferences as settings, and two changes would edit the same section twice. Change 01856e28 is closed when this one lands.\n- PS6 Project first; Workflow and Robot Wrangler adopt the pattern afterwards, reusing the row and nav components built here.\n\nGroups: Analysis (project language, merge threshold, zone pins); Dashboard (port, tagged Restart); Git and commits (git.failForward, git.autoCommitGenerated); Display (rex.showTokenBudget); Optional features (sourcevision.ask, rex.placementDraft, hench.runVerdict, with Tokens on the two that spend tokens); Connections (the Sidecar controls, including a new switch for web.sidecarGithubReads, which has no control today).\n\nRemoved from the page: the stats bar and the stability legend (inline tags replace it). The eight dead toggles, sourcevision.prMarkdown and the Sidecar trio leave under their own cleanup changes; after cleanup six toggles remain, down from 18 cards.\n\nSequencing: start after cleanup changes fbc4c752 (delete the eight dead toggles) and e782039b (remove the PR Markdown page). Those changes live on feat/ndx-feature-flags-audit-a580b1 and are not on main yet, so wire blockedBy once both are merged. The Sidecar unflag and default-on changes are independent; if they land first the redesign starts from a shorter list. Docs and help (change 4e541caf) should describe the new layout.\n\nOut of scope: search across settings pages; moving Workflow and Robot Wrangler to the new pattern; promoting or removing experimental.posixFreezeTreeKill; reading toggles from .n-dx.local.json. Open question for this change: the project language list offers Auto, TypeScript, JavaScript and Go only, though Python and Java packs exist."
