Redirect to a fixed loopback callback, http://127.0.0.1:<port>/oauth/callback (or localhost when the dashboard was opened on localhost), matching the document's redirect_uris (a port is allowed to vary). Carry the connection id and the project in the OAuth state (the state stays single-use, in memory, 10 minutes) instead of the redirect URL's query. The project server serves /oauth/callback as the page shell (public, like the shell already is); the viewer's captureSignInReturn reads code, state and iss from it and POSTs them with its session credential to the authenticated /api/connections/:id/oauth/finish, then routes to Settings > Project. Verify the iss parameter against the issuer (the server sets authorization_response_iss_parameter_supported).\n3. Through the hub (projects served at /p/<id>/), the callback lands on the hub's origin root: the hub serves GET /oauth/callback as a tiny public page that carries no credential and only forwards the browser, query intact, to /p/<project>/oauth/callback for the project named in an unauthenticated, non-secret routing field of the state (e.g. a short project segment before the random part). Unknown or missing project: a plain error page. No token, cookie or code is read or stored by the hub.\n4.
