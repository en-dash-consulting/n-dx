For each project server except ndx-sidecar, emit `enabled=false` plus a placeholder for the transport that server declares in the project file:\n- a stdio server (it has `command`): `-c mcp_servers.<name>.command=\"ndx-sidecar-disabled\"`;\n- a Streamable HTTP server (it has `url`): `-c mcp_servers.<name>.url=\"http://127.0.0.1:9/ndx-sidecar-disabled\"`.\nIf Codex loaded the file, the override replaces that one key and `enabled=false` keeps the server off. If it did not, the entry Codex builds from the overrides alone has exactly one transport and is disabled, so config loading succeeds. A server whose project entry declares neither `command` nor `url`, or both, refuses the turn naming the file and the server (fail closed), like the existing unparseable-file and non-bare-name refusals, which stay.
