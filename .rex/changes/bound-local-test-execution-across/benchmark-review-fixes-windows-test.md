Point to `NDX_TEST_MAX_WORKERS` for developers who want agent shell runs capped.\n\nTests:\n- the Windows path fix (the existing test passes on POSIX and the fix is platform-correct by construction);\n- an aborted no-slot batch is not summarized as failures, and the summary carries the interrupted line (drive `runBatch` / summary with fakes);\n- `sleep` resolves at once on an aborted signal;\n- escalation sends SIGKILL after the grace period (fake timers and a fake `activeChildren`).\n\nOperator notes: no real benchmark runs.
