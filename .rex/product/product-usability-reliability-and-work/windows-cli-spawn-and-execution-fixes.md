Type: Bug. Fix Windows-specific CLI execution issues that prevent N-DX from running reliably after installation.

User Story: As a Windows user, I want CLI execution to work reliably, so that N-DX commands run successfully in my environment.

Acceptance Criteria:
- Given N-DX is installed on Windows, when a supported command is run, then the command executes without platform-specific spawn failures.
- Given a command cannot execute, when the failure occurs, then the error message identifies the command and cause.
- Given Windows-specific handling is required, when commands are launched, then the implementation uses compatible process execution behavior.

Notes: May overlap with broader Windows install reliability but should remain independently trackable.
