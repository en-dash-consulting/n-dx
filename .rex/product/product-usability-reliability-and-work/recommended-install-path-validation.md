Type: Spike. Determine the most reliable and effective installation path for N-DX across expected user environments.

User Story: As a product team, we want to validate the most reliable install path, so that users receive clear setup guidance based on tested behavior rather than assumptions.

Acceptance Criteria:
- Given the available install options are reviewed, when validation is complete, then one preferred install path is recommended.
- Given the preferred path is identified, when documentation is updated, then users can follow one clear setup flow.
- Given alternate install paths exist, when they are documented, then they are clearly marked as secondary, experimental, or unsupported.

Notes: The team has not yet confirmed the best supported install method.
