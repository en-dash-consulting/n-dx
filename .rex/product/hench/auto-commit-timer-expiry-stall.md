When hench runs with --yes/--auto/--loop, a timer-expiry auto-commit ('Auto-commit: committed staged changes (timer expiry)') can stall the loop instead of advancing to the next task. The loop must recognize this event as a successful commit and proceed — either continuing from the committed state or skipping to the next task if the work is already fully committed.
