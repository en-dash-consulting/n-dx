Add a three-way density toggle next to the existing dark/light mode control in the dashboard header, letting users pick a compact (small), default (medium), or roomy (large) UI scale. Medium preserves today's spacing and font sizing as the baseline; small reduces padding, font size, and row heights for information-dense views; large increases them for readability. The selection should persist across sessions like the theme preference and apply globally to all dashboard views.
