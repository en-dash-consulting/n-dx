Add a unified Commands section to the web dashboard that surfaces all current CLI commands grouped by category (setup, analysis, planning, execution, configuration), with descriptions and trigger controls where available. Complements the existing per-view trigger controls by providing a single discoverable reference panel driven by a server-side manifest so new commands appear automatically.
