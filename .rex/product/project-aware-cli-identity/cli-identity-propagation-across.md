The web dashboard currently displays hardcoded 'ndx' command strings in button labels, help text, code snippets, and the new Commands section. This feature exposes the resolved cli.name via the server API, injects it into dashboard shared state, and replaces all hardcoded references so users working in projects with a different command name see accurate guidance throughout the UI.
