Extend the reshape pipeline so that when multiple sibling PRD items share the same base title differing only by hash suffix (e.g. 'Fix observation in global', 'Fix observation in global-a3f2', 'Fix observation in global-b91c'), they are consolidated under a newly created parent item. The parent inherits the shared base title, and the original children are renamed to distinct, descriptive titles derived from their individual descriptions/bodies via an LLM call. This addresses the proliferation of hash-disambiguated duplicates that currently clutter the PRD tree under epics like Code Health & Dependencies.
