Roadmap PR 36 (v2 Migration Path, card D1), based on roadmap PR 35 (feature be394022). On a v2 project the dashboard reads an empty v1 cache and shows "No PRD data found"; Quick Add and status PATCH fail with ENOENT; the PR 14 Product, Changes and capability views are built but only rendered from fixtures. This feature builds the PRD cache from rex's change-layer projection, routes the Product, Changes and capability views to real v2 data, and makes Quick Add create an Inbox change and status PATCH work on v2.

This is the no-break subset of Hal's feature 89ecd7f3 ("Dashboard on the v2 model"); Ryan owns this work by decision D7 of the v2 Migration Path (2026-10-12).

Design boundary (roadmap PR 36, D1; every change is checked against it):
- packages/web only (src and tests), following packages/web/AGENTS.md: the server → viewer layering, the gateway rules (all rex imports through packages/web/src/server/rex-gateway.ts, re-export only, type imports too), and the web→rex gateway export ceiling in tests/e2e/architecture-policy.test.js raised with a "Raised from X to Y for …" description entry (plus tests/integration/cross-package-contracts.test.js if it lists the gateway's exports). The viewer reaches server data only through routes, never by importing rex.
- Not rex, not hench. Consume rex's public API only (packages/rex/src/public.ts as exported by roadmap PR 34 T6: prdLayout, loadPrdModel, findNextWork, completeV2Work, ChangeLayerStore, buildChangeBrief, …; on a v2 tree resolveStore already returns the change-layer store since PR 33). If something web needs is not exported by rex, stop and report it rather than editing rex.
- v1 projects keep today's behaviour exactly.
- Fixtures: packages/rex/tests/fixtures/v2-tree (copy to a temp dir before anything writes).
- Add a patch changeset for @n-dx/web. Never major. Any field added to an /api route on v2 is listed in the changeset.

Decisions (assumed overnight 2026-10-12, Ryan to confirm): stack A's Q1–Q4 hold. D6 of the v2 Migration Path: the dashboard gets the no-break minimum; full type-aware CRUD, Quick Add preview and Prepare task on v2 stay in roadmap PR 21.
