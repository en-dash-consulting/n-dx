The evidence layer and the realized-by edge need commits tied to items. Today only hench auto-commits carry N-DX-Item, and its value is a dashboard URL (usually localhost). The trailer format freezes at 1.0.0, so its value becomes the item id.

Roadmap PR 5 · wave 0 · lane hench.
