The Windows CI leg runs 29.4 of its 30 allowed minutes; macOS and Linux spend 11 to 19. Setup and build are under two minutes on every leg, so the whole cost is the two test steps. Root cause review (run 38193308009): suites run strictly in series with 2.4 to 2.9 effective workers of 4; three e2e files (cli-ci, cli-init, cli-prd-bundle) form each suite's tail at 171 to 255s on Windows; git and CLI spawns run 13x to 17x slower on Windows with no Defender exclusion; web spends 65% of its wall time on per-file environment and import. Delivered as a stacked PR series, one task per layer, each PR recording the measured per-suite seconds from its own CI run.
