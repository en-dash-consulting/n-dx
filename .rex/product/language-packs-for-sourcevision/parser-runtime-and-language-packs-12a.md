Design-session decisions 6 and 7 (LS9) and step 4 of the agreed order: the tree-sitter parser runtime becomes its own package that only packs load, and Java, Go, SQL and Terraform become packs that sourcevision loads at run time. Go installs by default as an optional dependency of @n-dx/sourcevision; Java, SQL and Terraform are opt-in. Brief: workshop analysis/language-scaling/pr12-runtime-and-packs-brief.md.

Decided by Ryan 2026-10-13: opt-in packs install into a per-user pack directory, `<resolveNdxHome()>/packs/<sourcevision version>/` (`npm install --prefix`); SQL and HCL become packs here too, so sourcevision ends this feature with no web-tree-sitter, grammar or query; the install command, offline tarballs and the .n-dx.json pack list are the next feature (12b).

The packages exist already (operator scaffolding commit on this branch): @n-dx/lang-runtime, @n-dx/lang-java, @n-dx/lang-go, @n-dx/lang-sql, @n-dx/lang-terraform, each with package.json, tsconfig, vitest config, AGENTS.md + CLAUDE.md, a placeholder export; workspace, lockfile, changeset, `fixed` group, release PACKAGES lists and the pack-tier boundary test are wired. sourcevision has @n-dx/lang-go as an optional dependency and the other four as devDependencies, and the vitest configs of sourcevision, web and graview alias every @n-dx/lang-* package to its src/index.ts. Agents cannot run `pnpm install`: never add, remove or rename a dependency; if a task needs one, stop and say so.

Rules for every task:
- Moves use `git mv` so history follows; behaviour, comments and notice wording move unchanged unless the task says otherwise.
- No pack imports another pack. No tree-sitter type enters @n-dx/lang-kit.
- Corpus and comparison scripts stay in packages/sourcevision/scripts and import the packs from the workspace (a pack never depends on sourcevision).
- Do not touch rex, hench, core or web source. No language SDK or toolchain at run time (LS16).

The bar: with the Java and Go packs present (the workspace), analysis output stays byte-identical to PR 11 and the Java, Go and SQL corpus reports give PR 11's numbers (Java 99.93% clean; Go on gitea 98.69% clean, import parity 3130/3131, edge parity pack 13077 edges / 11537 external pairs). Gates after every task (rebuild first): each lang-* package's `npx vitest run`; `cd packages/sourcevision && SV_REQUIRE_GRAMMARS=1 npx vitest run` (the operator runs this one: agents cannot set the variable); the root policy suites (architecture-policy, domain-isolation, instruction-alignment, layout-literal-policy, agents-md-size-budget, prd-line-endings, ci-merge-queue-trigger, iso-skill-drift, shell-spawn-inventory-policy, wall-clock-inventory-policy, obfuscated-code-policy).
