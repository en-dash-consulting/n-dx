LS13 and LS14: find the databases a repository uses and the SQL dialect it writes, from five signals (IaC, container images, dependencies, config, schema and migrations), held in memory. Dialect and table names only: no full SQL parsing. NoSQL engines are detected from drivers and config. Persisting database resources and code-to-database links into infrastructure.json waits for the conversation with Sterling H. Config is read for key names and URL schemes only: hosts, users and passwords are never stored or logged.

Side stack, PR 9. Uses the Java and Go packs' call captures for embedded SQL.
