Milestone L3. Turn Java captures into the import graph sourcevision already uses, so Java repositories get zones, cohesion, coupling and findings like TypeScript and Go. Java needs no import for a class in the same package, so an import-only graph misses edges; the resolver keeps a per-package type index for bare type names.

Edges use the existing ImportEdge and ExternalImport shapes. No new required fields and no change to sourcevision MCP tool shapes. Accuracy is measured against scip-java on the drift corpus, where scip-java serves as the answer key; scip-java is a manual measurement tool here, not a runtime dependency.

Phase 2 · one PR · gate G2 (resolver measured).
