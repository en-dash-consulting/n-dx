LS11 (decided 2026-10-08): port Go to tree-sitter now, with today's regex import parser (analyzers/go-imports.ts) and route detection as the parity answer key. This feature builds the grammar, the structure queries and generated-file detection, and measures parse rate and import parity on a pinned corpus. Go keeps using the regex parser for import edges in this PR; switching to the pack is the next feature.

Side stack, PR 6: cut from the Java PR 4 tip and run in a parallel session. Java PR 4 and PR 5 are merged into this branch later (merges only, no rebase), so keep shared files (pack.ts BUILTIN_PACKS, build-grammars.mjs GRAMMARS, detect.ts, ci.yml) to small additive edits.
