Milestone L2. The first pack: Java is recognised as a language, its files get roles in the inventory, and the Java queries extract packages, imports, type declarations, method spans, method calls and type references. No import resolution yet (that is the next feature), so the import graph for Java repos is unchanged in this PR.

Seeds the drift corpus: pinned public repositories used to measure the pack now and to catch grammar or rule drift later.

Phase 1 · one PR · gate G1: at least 98% of .java files in the drift corpus parse without ERROR or MISSING nodes.
