Milestone L4. Extend the module reader with dependencies and versions: dependency coordinates with versions, the Java version, and the Spring Boot version when present. Maven pom.xml is data and is read exactly. Gradle build scripts are programs, so values read from them are best-effort and marked as such; the version catalog (gradle/libs.versions.toml) is data and is read exactly.

Scope for this phase: the build model stays in memory, used by the Java pack and covered by fixtures. Persisting versions into analysis artifacts, attaching them to externals and checking them against end-of-life data wait for phase 3, after the conversation with Sterling H about the meta-scan and readiness artifacts. No edits to project-profile.ts and no new committed paths.
