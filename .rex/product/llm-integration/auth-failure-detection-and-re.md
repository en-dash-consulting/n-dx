When an LLM provider preflight or runtime call returns a 401 or authentication error, ndx currently dumps the raw CLI JSON payload to the console. This feature adds structured detection for auth failures across all providers, maps them to a typed error, and replaces the raw-JSON dump with a concise, actionable message telling the user exactly which provider failed and what commands to run to fix their credentials.
