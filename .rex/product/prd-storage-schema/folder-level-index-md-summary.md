Repurpose `index.md` inside each PRD item folder as an auto-generated summary of the folder's contents. The new `index.md` aggregates: a completion table for child items, the commit list per task (sourced from new commit-attribution metadata), a prose summary, a change list, and basic item info. The file is regenerated on every PRD write so it stays in sync with the underlying tree.
