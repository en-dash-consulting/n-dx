When hench produces a commit, append a structured trailer block identifying that n-dx authored the change, the vendor and model used (e.g. claude / claude-opus-4-7), and a permalink to the n-dx dashboard view of the run/PRD item. Reviewers reading the commit on GitHub should be able to trace the work back to the autonomous run that produced it.
