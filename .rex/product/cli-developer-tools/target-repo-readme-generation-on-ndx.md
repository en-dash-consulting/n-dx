When `ndx init` runs, generate a README for the repository being initialized (not n-dx itself). If no README exists, write README.md; if one exists, write README.proposed.md without touching the original. Today the init flow conflates the host tool's documentation with the target project's, leaving users with either a missing or misleading README.
