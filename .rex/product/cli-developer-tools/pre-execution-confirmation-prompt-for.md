Before ndx self-heal begins executing tasks against discovered findings, surface an interactive confirmation prompt that lists the tasks queued for work and requires explicit user approval to proceed. Bypass the prompt when the user passes --auto/--yes or when a persistent config flag (e.g. selfHeal.autoConfirm) opts into automatic execution, preserving unattended self-heal pipelines while preventing surprise long-running runs in interactive sessions.
