Ensure that every n-dx Claude Code skill invoked outside hench run paths (e.g., simplify, code-review --fix, fewer-permission-prompts, update-config, init) stages and commits its changes immediately after completing, with a task-scoped commit message. This behavior is strictly scoped to external skill invocations — the hench agent loop has its own commit lifecycle and must not be modified.
