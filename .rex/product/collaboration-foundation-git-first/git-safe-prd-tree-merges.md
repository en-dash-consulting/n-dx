Discovery Option 2. The PRD tree is designed to be committed, but raw git merges are currently unsafe: title-only slugs collide across branches, removeStaleEntries silently bulk-deletes from stale snapshots, and there is no merge driver or post-merge validation. This feature makes divergent-branch PRD editing safe.
