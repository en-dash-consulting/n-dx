description: "Invert the enrichment default from \"generate everything, then filter with regexes\" to \"compute facts, let Jev judge, generate only where the judgment is uncertain, then verify what was generated.\" Evidence from the 2026-09-21 live runs on this repository: 27 of 30 generated findings were `structural` paraphrases of cohesion/coupling numbers pass 0 already emits; the four Claude enrichment batches were 27k of a 29.6k-token phase and all of its wall-clock, while the Jev judgment step over the same findings and 26 zones took three requests and seconds. Jev judgments are cheap, idempotent and cannot be malformed, so most of the machinery that exists to manage expensive generation (`PASS_CONFIGS` iterative deepening, attempt ladders, `tryParseJSON` fence recovery, `isSpeculativeFinding`, `mergeZonesByName`, per-zone content-hash skips, the meta pass) has no job once generation is opt-in.\n\nFour steps, in order; each is shippable on its own and the earlier ones do not flip any default.\n\n**1. Verify and anchor (extend `analyzers/enrich-judge.ts`).** After `extractFindings`, the existing per-batch Jev request gains, per finding: a Noul *\"is this claim supported by the evidence shown (file list, headers, crossings)?\"* replacing `isSpeculativeFinding`; a Noul *\"does this restate a metric already present in the heuristic findings?\"* (state carries the pass-0 findings for the same scope) so paraphrases are dropped; a Choice over the scope zone's files (≤255, sample if larger) to fill `Finding.anchors` — the schema field documented as \"empty ⇒ unverified hypothesis\" that nothing fills today; a Choice over `FindingType` and a Choice over zone ids for `type` and `scope`, so `findingsContract`/the JSON examples stop asking the text model for those fields too (`stripJudgedFields` extends to them). Unsupported findings are dropped; anchors carry the choice probability. Questions are independent, so they share the request with severity/category.\n\n**2. Judgment cache.** `.sourcevision/.cache/judgments.json`: key = sha256 of canonical JSON of (state slice the question references, question); value = answer + model + timestamp. `askJev` callers consult it through one helper; cache hits make no request. Re-runs re-judge only changed inputs. The per-zone content-hash enrichment skip in `enrich.ts` becomes redundant and is removed. Machine-local, safe to delete; add to the Key Files table.\n\n**3. Cascade as the default `analyze` path.** Pass-0 heuristics and zone metrics feed one merged Jev request: per zone the two fragility Nouls (exists); per heuristic finding a Noul *\"given these files, is this a real problem or a detection artifact?\"*; per crossing-heavy file a Choice *\"which zone should this file live in?\"* over the zone list plus `stay`, feeding `move-recommendations.ts`. Code bands probabilities: ≥ 0.7 → templated `warning` finding (no prose); ≤ 0.3 → dropped or `info`; 0.3–0.7 → escalation set. Generation runs only for the escalation set and zones that failed a fragility Noul, using today's per-zone prompt with file headers; its output goes through step 1. `--narrate` restores the full generative pass over every zone with today's prompts and pass machinery; without it `PASS_CONFIGS`, `computeAttemptConfigs`, `runMetaEvaluation` and `mergeZonesByName` are not on the path. Zone descriptions are templated from facts (file count, dominant archetypes, entry points, top import partners). CONTEXT.md is templated from `zones.json` + findings by default; `context.distill` runs only under `--narrate`.\n\n**4. Zone naming as selection.** Deterministic candidates per zone: `package.json` name if the zone maps to one package, dominant directory title-cased, top-two directories joined, dominant-archetype noun (\"CLI Commands\", \"Route Handlers\"). One Choice with `none`. The same request carries Nouls over graph-prefiltered zone pairs (shared directory prefix or crossing density above a code threshold): *\"are these two zones the same architectural concept?\"* — replacing `mergeZonesByName` string equality. `none` zones get three generated names from the text model, then a Choice among them plus a Noul *\"does this name describe these files?\"*; a failed Noul falls back to the algorithmic name.\n\n**Gate for flipping the default (step 3):** run `pnpm gauntlet:evals` on the fixture repositories with and without the cascade; the cascade must retain ≥ 80% of the goldens' actionable findings (severity ≥ warning, non-paraphrase) and every golden zone must map to a named zone. Record both numbers in this item's log. If it misses, ship the cascade behind `--judge` instead and leave today's default.\n\n**Out of scope, capture separately:** the rex `analyze` pre-filter (Noul *actionable as a task?* + Choice over existing epics before proposals are generated); tightening the `utility` archetype criteria in `archetypes.ts`.\n\nThresholds (0.3/0.7 bands, pair-prefilter density) live in code. Request budgets, Jev per-token cost and request-size ceiling are unmeasured — record them from the live runs in the log."
