description: "Produce `routes` and `outboundCalls` facts for Spring Boot code from the Java pack. Facts only: nothing is persisted in this task (the next task wires them into components.json and outbound.json).\n\nContract (packages/lang-kit/src/pack-contract.ts, additive): OutboundCallFact gains optional `confidence: \"certain\" | \"likely\" | \"inferred\"`, documented with the same meaning as sourcevision's Confidence on OutboundDependency (how sure we are that this is an outbound call at all, not where it points). Move `routes` and `outboundCalls` from DECLARED_FACT_KINDS to PRODUCED_FACT_KINDS; update the contract tests. RouteFact keeps `method` optional (absent = any method).\n\nFramework module (packages/lang-java, e.g. src/spring.ts): fills lang-runtime's reserved FrameworkPack slot (id `spring-boot`, provenance per rule: versions verified against, date, source URL, as the queries record). Reads the existing `annotations`, `declarations`, `methods` and `calls` captures; add queries only if a capture is missing, and keep every existing golden unedited.\n- Routes: a class annotated `@RestController` or `@Controller` with an optional class-level `@RequestMapping` prefix; methods with `@GetMapping`, `@PostMapping`, `@PutMapping`, `@DeleteMapping`, `@PatchMapping`, or `@RequestMapping(method = RequestMethod.X)`; paths from the single value, `value =` or `path =`, including arrays (`{\"/a\", \"/b\"}` gives two routes). Join prefix and path with exactly one slash. Handler = the method name. A path that is not a string literal (a constant, a concatenation) is skipped and counted in the pack's notices, not guessed. `@RequestMapping` with no method yields a RouteFact with no method.\n- Outbound calls (kind, client, target, targetSource, confidence):\n  - http: RestTemplate (getForObject, getForEntity, postForObject, postForEntity, put, delete, exchange, execute), WebClient (`.get()/.post()/… .uri(...)`, `WebClient.create(url)`), RestClient (Spring 6.1, same shape), `@FeignClient(name, url)` (one fact per client interface; url when given, else the `name` as target with targetSource `config`), java.net.http.HttpClient with `HttpRequest.newBuilder(URI.create(...))`.\n  - queue: KafkaTemplate.send(topic, …) and `@KafkaListener(topics = …)`; JmsTemplate.send/convertAndSend(destination, …) and `@JmsListener(destination = …)`; RabbitTemplate.convertAndSend(exchange, routingKey, …) and `@RabbitListener(queues = …)`. Producers and consumers both count, as Hal's kafkajs rule in sourcevision's outbound-detection.ts does.\n  - grpc: ManagedChannelBuilder.forAddress(host, port) / forTarget(target).\n  - env: System.getenv(\"NAME\") → kind env, target NAME, targetSource env.\n  - Targets: a string literal is `literal`; a Spring placeholder `\"${orders.url}\"` (alone, or as the leading part of a literal) is `config` with the key (`orders.url`) as target; anything else is `unknown` with target `\"\"`. Confidence: a direct call on a field or parameter whose declared type is the client class is `certain`; a call whose receiver type is not known but whose method name and arguments match is `likely`; never guess beyond that.\n- The Java pack's entry produces routes and outboundCalls when asked (`kinds`), alongside imports, symbols and calls; asking only for imports costs no extra work.\n\nGoldens (packages/lang-java/tests/fixtures): a Spring fixture covering every rule above, including arrays, prefix joining, a constant path (skipped), a placeholder target, a consumer annotation and a `likely` call. Corpus: a script beside packages/sourcevision/scripts/java-corpus-report.mjs (or a section in it) printing per repository the route count, outbound count by kind and client, skipped paths, and 15 random facts of each type with file:line for a hand check. Append spring-petclinic and thingsboard numbers to this task's log. The Java corpus report's existing lines must not change.\n\nNo package.json dependency changes; do not touch rex, hench, core or web source, or sourcevision's outbound-detection.ts / server-route-detection.ts / components.ts (next task)."
