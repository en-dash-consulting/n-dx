A catalog value such as `x = \"\\UFFFFFFFF\"` throws `RangeError`. gradle-catalog.ts catches only `TomlSyntaxError` and rethrows anything else, so one malformed `gradle/*.versions.toml` aborts the Gradle build-model read instead of producing a notice.
