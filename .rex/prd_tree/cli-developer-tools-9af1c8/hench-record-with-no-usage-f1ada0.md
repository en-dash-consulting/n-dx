description: "**Severity:** high — **Verdict:** should-fix (captured from /ndx-adversarial-review of branch `chore/pr-329-review-followups`, 2026-08-25)\n\n**Failure scenario.** `packages/hench/src/cli/commands/record.ts:208` passes `flags.since || flags.startedAt` into `readUsageDelta`. There are two ways that reaches the delta computation as \"no window\", and both are silent:\n\n1. **Neither flag given.** `since` is `undefined`, so `packages/hench/src/store/session-usage.ts:147` computes `sinceMs = Number.NaN` and `:148` sets `fresh = scanned` — every usage-bearing message from the cursor onward. With no watermark yet for the session, the cursor is empty and the window opens at the top of the transcript. That one PRD item absorbs the entire session's spend. The module's own docblock (`session-usage.ts:99-112`) records the measured case: 549 messages and 127M cache-read tokens, four earlier tasks' spend included.\n2. **A malformed value given.** `Date.parse` returns `NaN` for anything it cannot read, and the code takes the identical branch. Verified: `Date.parse('25/08/2026')` → `NaN`. A locale-formatted `Get-Date` on a non-US machine produces exactly that shape, and the skill bodies' escape hatch — \"or a timestamp your environment already exposes\" — invites it.\n\nThe asymmetry is the crisp statement of the defect: `--turns=abc` is a hard `CLIError` (`record.ts:292-302`), while `--startedAt=abc` is accepted, ignored, and the resulting 100M-token record is written and reported as fact.\n\n**Reachability.** `hench record --task=abc123 --status=completed` is the **first documented example** in `packages/hench/src/cli/help.ts:120` and carries no `--startedAt`. Any hand-run or third-party record hits trigger 1.\n\n**Already covered?** Only at the instruction layer. Tasks `f050baf6` and `08ceeb30` fixed the six skill bodies to pass `--startedAt`, and `tests/e2e/skill-run-recording.test.js` guards that they keep doing so. The CLI itself has no guard, no default, and no warning. `f050baf6` explicitly listed this as its *unchosen* solution #2: \"Change the default in `record.ts` so a missing `--startedAt` means 'since the last record only, never the whole transcript'. Fixes all callers at once including third-party ones, but changes documented CLI behavior and would need its own regression tests.\" That reasoning is sound as far as it goes, but it left the tool layer with no diagnostic at all — which is what this item addresses.\n\nTrigger 2 is new information not present in either prior item. Note that `packages/hench/tests/unit/store/session-usage.test.ts:259` (\"ignores an unparseable window start rather than dropping everything\") pins the current NaN behavior deliberately — so this is a considered trade, not an oversight. The point is that a third option, rejecting the flag, was never on the table.\n\n**Refutation attempted.** Confirmed `Get-Date -Format o`'s 7-digit fractional seconds parse correctly (`Date.parse('2026-08-25T09:26:19.7760593-07:00')` is valid), so the prescribed format is not itself the trigger. Checked for a warning on the unbounded path: the only output is `record.ts:229`, which reports the total as a plain fact (\"Token usage read from this session's transcript: N tokens across M messages\") with nothing marking it as suspicious.\n\n**Decision to make.** Whether an unparseable window value should be a hard error or a warning. This review recommends hard error for the malformed flag (it is unambiguously operator error, and `--turns` sets the precedent) and a warning — not an error — for the genuinely windowless case, since recording a whole session is legitimate when that is what actually happened.\n\n**Possible solutions.**\n1. *Recommended.* Validate `--startedAt`/`--since` with a `Date.parse` check that throws a `CLIError`, and warn when a transcript-derived record has neither a window nor a cursor. Cost: roughly 20 lines plus tests. Risk: a script passing a sloppy timestamp starts failing — intended, but it is a behavior change worth a changeset note.\n2. Warn on both triggers, reject neither. Non-breaking and cheaper, but a stderr warning is easy to miss and the wrong number still lands in `get_token_usage` and `ndx usage`.\n3. Default the window when absent — e.g. to process start. Rejected: it would attribute spend the record cannot vouch for, which is the same failure mode with the sign flipped."
